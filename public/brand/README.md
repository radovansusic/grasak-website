# Grašak - logotip

Izvor: GRASAK_logo_vektor (Adobe Illustrator PDF), pretvoren u SVG.

- `grasak-logo.svg` - logo s natpisom "Dječiji frizerski salon". Boja = CSS `color` (currentColor), pa se mijenja bez novog fajla: `<div style="color:#45813D">...svg...</div>`.
- `grasak-znak.svg` - bez natpisa, za ikonice i male veličine. Detalji graška: CSS varijabla `--grasak-detalj` (zadano bijela).
- `grasak-logo-zuta.svg` (#EDB21E, originalna), `-zelena.svg` (#45813D, boja sajta), `-crna.svg` (#231F20), `-bijela.svg` - fiksne boje za štampu, Canva, društvene mreže.
- `/icon-192.png`, `/icon-512.png` - ikonica aplikacije (žuti znak na bijelom).
